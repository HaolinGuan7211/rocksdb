## 7. Logic Update (Post-review)

Following review feedback, three model gaps were explicitly addressed in code:

- DRAM baseline latency is now explicitly counted in read delay:
  - seq read base: `dram_read_seq_ns` (default `81ns`)
  - rand read base: `dram_read_rand_ns` (default `101ns`)
  - read total now tracks `queue + xp_service + dram_base`.
- RPQ arbitration overhead is now modeled explicitly:
  - new knob: `xp_rpq_arb_ns`
  - per-read arbitration penalty is `outstanding_reads * xp_rpq_arb_ns`
  - read total now tracks `queue + xp_service + dram_base + rpq_arb`.
- XPBuffer is now modeled as a shared read/write resource:
  - switched from a single timeline lock to a capacity-bound mock buffer
  - key shape is `tag(file_name) + line(offset/xp_line_bytes)` with LRU eviction
  - when shared mode is enabled, writes inject lines into the same buffer and can evict read-prefetch lines
  - mixed read/write impact is reflected through read hit-rate drop and higher XP read service delay.

New observable stats include:

- `simulated_read_dram_delay_ns`
- `simulated_read_arb_delay_ns`
